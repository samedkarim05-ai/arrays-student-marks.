01 / THE BASICS

What is an array?

An array is a data structure that stores multiple values of the same type under one variable name. Each value has a position called an index.

Instead of creating a separate variable for every student's mark, one array can keep all the marks together. In JavaScript, array indexes start at 0.

02 / WHY ARRAYS MATTER

Why are arrays important?

01

Keep data together

Related marks can be stored under one variable name.

02

Reduce repeated code

A loop can process each mark without repeating instructions.

03

Make calculations easier

Calculate totals, averages, highest marks, and lowest marks.

04

Access values by index

Read or update a value using its position in the array.

03 / REAL-WORLD APPLICATION

Student Marks Management System

Schools and teachers need to record and review students' marks. An array stores a set of marks and allows the program to process them together.

How it works

  1. Store the marks in an array.
  2. Use a loop to visit each mark and calculate the total.
  3. Display the average, highest mark, and lowest mark.

Why arrays are necessary: they keep marks organized and let the same calculation work for every student. A real school system may also use a database to save records permanently.

JavaScript code example
const marks = [75, 80, 65, 90, 70];
let total = 0;

for (let i = 0; i < marks.length; i++) {
  total += marks[i];
}

const average = total / marks.length;
console.log(average); // 76

marks stores the values. The loop processes each element, and marks.length tells us how many values are stored.

In conclusion

Arrays are useful when a program needs to store and process many related values. In a Student Marks Management System, an array keeps marks together and makes it easier to calculate results with loops. This shows how a basic data structure can solve a real-world problem.
